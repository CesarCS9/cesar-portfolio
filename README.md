# Cesar Castillo — Portfolio

This is my personal front-end development portfolio, created as part of my studies at Noroff.

The portfolio showcases my projects, skills, background and experience as a Front-End Development student.

## Description

The portfolio was designed to present my work in a simple, modern and responsive way. It includes selected projects, information about my background, the technologies I work with and links to my CV and contact details.

The portfolio includes projects such as:

- Rainy Days
- Community Science Museum
- STUFF..

### Running the project

Open the project in Visual Studio Code and use a local development server such as Live Server to run the website.

## AI Usage

AI tools, mainly ChatGPT, were used during the development of this portfolio as a learning and development support tool.

AI was used for:
- Explaining HTML, CSS and JavaScript concepts
- Troubleshooting and debugging
- Discussing possible solutions and development approaches
- Accessibility and responsive design guidance
- Improving documentation and non-technical text
- Reviewing and refining parts of the implementation

AI suggestions were reviewed, tested and adapted before being used. I remained responsible for the implementation and final technical decisions.

AI was not used to generate the portfolio or major components as a complete solution. The code and implementation were developed and adapted by me.
